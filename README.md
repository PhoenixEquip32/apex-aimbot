# Apex Aimbot

Download: soon

Aim assist for Apex Legends with FOV, smoothing and bone control. External overlay, no injection.

Targets: nearest, lowest HP, crosshair. Filters: knocked, teammates, visible only. Modes: hold or latch, keybind rebindable.

Requires Windows 10/11, EA App, admin rights. Loader first, then game, INSERT for menu. EAC, so keep the build updated.
